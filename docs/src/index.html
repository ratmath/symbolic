@ratmath/symbolic

Algebra on expressions, with every step checked

Expand, factor and simplify expressions the way a computer algebra system does, with one difference: the exact and certified libraries sit underneath, so an answer says whether it is proven, refuted or undecided and is never just asserted.

What is here

This is the first part of the package: expressions, assumptions, rewriting and equality. Solving, antiderivatives, limits and step records are planned and listed at the bottom of this page.

A first program

import { sym, expand, factor, simplify, equal, rewrite, rules } from "@ratmath/symbolic";

String(expand("(x + 1)^3"));              // "x^3 + 3*x^2 + 3*x + 1"
String(factor("x^4 - 1"));                // "(x + 1)*(x - 1)*(x^2 + 1)"
String(simplify("(x^2 - 1)/(x - 1)"));    // "x + 1"

String(equal("sin(2x)", "2sin(x)cos(x)"));   // equal: a proof
String(equal("sqrt(x^2)", "x"));             // different at x = -2/3: also a proof
String(equal("sqrt(x^2)", "x", { assume: { x: "positive" } }));   // equal
String(equal("atan(1)", "pi/4"));            // undecided, and it says so

Expressions are written in calculator notation: 2x, x^2, sqrt(x), sin(x), log for the natural logarithm, pi and e. Every function takes text, an Expr or the plain tree that analytic and graphics share, so an expression can be simplified here and then plotted or integrated there.

Three ideas

Equality has three answers. Two expressions are proven equal when they reduce to the same normal form, proven different when a certified evaluation at an exact point separates them, and undecided otherwise. A numerical agreement is never reported as equality. See Equality.

Rules know their domains. \(\sqrt{x^2}\) is \(|x|\), not \(x\), and \(\log(ab) = \log a + \log b\) needs \(a\) and \(b\) positive. A rule is applied only when its conditions are proven from the assumptions you state; otherwise it is left alone and reported, or applied with the conditions handed back. See Rules and Assumptions.

Rewrites are checked. Each application of a rule is compared at exact test points with certified arithmetic, so a rule that is simply wrong is caught the first time it is used.
