Limits

Limits in closed form

limit gives the exact value of a limit where the standard methods find one, says when the two sides disagree, and compares its answer with the certified limit from analytic.

Using it

import { limit } from "@ratmath/symbolic";

const r = limit("(x^2 - 1)/(x - 1)", "x", 1);
String(r);          // 2   (x -> 1; cancel, then substitute; confirmed by certified evaluation)
r.kind;             // "finite"
String(r.value);    // "2"
r.method;           // "cancel, then substitute"
r.confirmed;        // true

String(limit("sin(x)/x", "x", 0).value);                  // 1
String(limit("(1 - cos(x))/x^2", "x", 0).value);          // 1/2
String(limit("(2x^2 + 1)/(x^2 - 3)", "x", "inf").value);  // 2
String(limit("sqrt(x^2 + x) - x", "x", "inf").value);     // 1/2
String(limit("(1 + 1/x)^x", "x", "inf").value);           // e
String(limit("sin(a*x)/x", "x", 0).value);                // a

The point is an expression, or "inf" or "-inf". The option { side: "left" } or { side: "right" } asks for a one-sided limit.

The kinds of answer

kindMeaning
"finite"The limit is value, an exact expression.
"inf", "-inf"The expression grows without bound, with that sign.
"none"The one-sided limits differ; reason gives both.
"numeric"No closed form was found, but analytic certified an enclosure of the limit (enclosure).
"unknown"Nothing was found. \(\sin x\) at infinity is an example: it has no limit, and the library does not claim to prove that.
String(limit("1/x", "x", 0));        // no limit: -inf from the left, inf from the right
String(limit("1/x^2", "x", 0));      // inf
String(limit("abs(x)/x", "x", 0));   // no limit: -1 from the left, 1 from the right
String(limit("abs(x)/x", "x", 0, { side: "left" }).value);   // -1

How a limit is found

Cancel, then substitute. The expression is put in normal form, which cancels common factors: \((x^2-1)/(x-1)\) becomes \(x + 1\). If the result is defined near the point on the side in question, its value there is the limit, by continuity.

Leading terms. When numerator and denominator both vanish (or the denominator alone does), each is expanded about the point:

\[ \frac{N(x)}{D(x)} = \frac{n_p (x-a)^p + \cdots}{d_q (x-a)^q + \cdots}. \]

If \(p > q\) the limit is 0; if \(p = q\) it is \(n_p/d_q\); if \(p < q\) the quotient is unbounded, with a sign fixed by the signs of \(n_p\), \(d_q\), the side, and whether \(q - p\) is even. This is l'Hôpital's rule applied as many times as needed, done in one step: differentiating \(p\) times is exactly reading off the first nonzero coefficient. The coefficients come from taylor and are exact.

At infinity. Put \(x = 1/t\) and let \(t \to 0\) from the right. Square roots are tidied using \(t > 0\), so \(\sqrt{x^2 + x} - x\) becomes \((\sqrt{1 + t} - 1)/t\), whose leading terms give \(1/2\).

Powers with the variable in the exponent. For \(f^g\) the limit of \(g\log f\) is found first, and the answer is its exponential. That is how \((1 + 1/x)^x \to e\).

The cross-check

When the expression has no other letters, analytic can often certify an interval that contains the limit, by a different argument from the one used here. If the closed form lies in that interval, confirmed is true. If it lies outside, the closed form is dropped and the certified interval is returned instead, as a "numeric" answer.
