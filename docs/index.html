@ratmath/symbolic

Algebra on expressions, with every step checked

Expand, factor, simplify, solve and integrate expressions the way a computer algebra system does, with one difference: each rewrite is checked by the exact and certified libraries underneath, so an answer is marked proved, refuted or undecided and never just asserted.

Planned, not built yet. This site is the frame the package will grow into. The full plan is in the library roadmap, and the RatMath Shelf page lists what exists across all the libraries.

What it will cover

  • Expressions with assumptions (x > 0, n an integer), and rewriting: expand, collect, factor, cancel, simplify.
  • Equality of expressions with three outcomes: proved equal, proved different, or undecided.
  • Solving equations and inequalities in one variable, with exact solution sets.
  • Antiderivatives that are verified by differentiating, limits, and series expansions.
  • Systems of equations, trigonometric families of solutions, and sums in closed form.
  • A record of the steps of every operation, for showing work.

How the docs will be laid out

Like every library on the Shelf: this overview, an Explore page for trying things without writing code, a Reference listing every function, and one page per topic that explains the usage and the mathematics. Every page ends with a box of code you can edit and run.
