Sums

Sums in closed form

sum finds ∑k=abf(k)\sum_{k=a}^{b} f(k)∑k=ab​f(k) in closed form by the methods of the course: sums of powers, geometric sums, telescoping. Each answer comes from an antidifference that is proven before it is used.

Using it

import { sum } from "@ratmath/symbolic";

String(sum("k", "k", 1, "n").value);              // n*(n + 1)/2
String(sum("k^3", "k", 1, "n").value);            // n^2*(n + 1)^2/4
String(sum("k*2^k", "k", 0, "n").value);          // 2*(n*2^n - 2^n + 1)
String(sum("r^k", "k", 0, "n - 1").value);        // (r^n - 1)/(r - 1), provided r != 1
String(sum("1/(k*(k+1))", "k", 1, "n").value);    // n/(n + 1)

String(sum("1/(k*(k+2))", "k", 1, "inf").value);  // 3/4
String(sum("k/2^k", "k", 1, "inf").value);        // 2
String(sum("1/k^2", "k", 1, "inf"));              // = pi^2/6   (known value (Basel problem (Euler)); checked)
sum("1/k", "k", 1, "inf").diverges;               // true

const s = sum("k^2", "k", 1, "n");
String(s.antidifference);    // k^3/3 - k^2/2 + k/6   — proven: F(k + 1) − F(k) = k^2
s.verified;                  // "proven"

The arguments are the term, the index, and the two ends; an end may be an expression in other letters or "inf". The result has value (an Expr, "inf", "-inf" or null), antidifference, method, verified, diverges, conditions and steps.

Antidifferences

Summing is to differences what integrating is to derivatives. If F(k+1)−F(k)=f(k)F(k+1) - F(k) = f(k)F(k+1)−F(k)=f(k), the sum telescopes:

∑k=abf(k)=∑k=ab(F(k+1)−F(k))=F(b+1)−F(a). \sum_{k=a}^{b} f(k) = \sum_{k=a}^{b} \bigl(F(k+1) - F(k)\bigr) = F(b+1) - F(a). k=a∑b​f(k)=k=a∑b​(F(k+1)−F(k))=F(b+1)−F(a).

So the work is finding FFF, and the check is easy: the normal form of F(k+1)−F(k)−f(k)F(k+1) - F(k) - f(k)F(k+1)−F(k)−f(k) must be 0. Every closed form returned has passed that check (verified: "proven"). When the ends are whole numbers, the terms are also added up one by one and compared with the closed form.

A polynomial term, with numbers or letters as coefficients, is a combination of these.

Telescoping. A rational function of kkk is split into partial fractions. Two terms c/(k+b)c/(k+b)c/(k+b) and c′/(k+b+j)c'/(k+b+j)c′/(k+b+j) whose poles are a whole number jjj apart nearly cancel in the sum, because

When the coefficients of each such group add up to zero, the group has a rational antidifference. When they do not, as for ∑1/k\sum 1/k∑1/k, the partial sums are not a rational function of the end (they are the harmonic numbers), and the library says so.

Infinite sums

∑k=a∞f(k)\sum_{k=a}^{\infty} f(k)∑k=a∞​f(k) is the limit of F(n+1)−F(a)F(n+1) - F(a)F(n+1)−F(a). A polynomial times rnr^nrn tends to 0 when ∣r∣<1|r| < 1∣r∣<1, and a telescoping remainder ∑c/(n+b+i)\sum c/(n+b+i)∑c/(n+b+i) tends to 0; otherwise limit is asked. Divergence is proven when the terms do not tend to 0, or, for a rational term of size about 1/k1/k1/k, by comparison with the harmonic series.
